# 엄마랑 경주 여행 🌸

엄마와 함께하는 경주 여행 계획 사이트입니다. 정적 HTML/CSS/JS로 만들어져 별도 빌드 없이 Vercel에 바로 배포할 수 있습니다.

## 구성
- `index.html` — 페이지 구조 및 콘텐츠 (숙소 추천 / 일정 추천 / 맛집 추천 / 준비물 & 팁)
- `style.css` — 스타일
- `script.js` — 탭 전환 동작

## 로컬에서 보기
`index.html`을 브라우저로 열면 바로 확인할 수 있습니다.

## Vercel 배포
1. GitHub에 이 저장소를 push
2. [vercel.com](https://vercel.com)에서 New Project → 해당 GitHub 저장소 선택
3. Framework Preset: **Other** (정적 사이트이므로 빌드 명령 없이 그대로 배포)
